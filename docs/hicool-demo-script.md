# HICOOL 法律智能工作站演示主线

演示使用一个连续案件会话，全程由 MTClaw Function Router 自动选择 Subagent，用户不手动切换模式。

## 场景一：案件材料接收

上传案件录音、聊天记录和证据材料，要求生成转写、案件要素、证据目录、时间线和主体关系图。

预期路由：`legal_case_intake`。

## 场景二：企业信息调查

针对案件主体查询工商、股权、关联企业和风险信息，并回填到主体关系与风险提示中。

预期路由：`legal_research`，调用企业信息适配器。

## 场景三：法规与类案检索

基于自动识别的争议焦点检索法规、司法解释和类案，生成带来源的类案检索报告。

预期路由：`legal_research`，调用法规库和案例库工具。

## 场景四：合同审查

上传涉案合同，指定审查立场，输出风险分级、原文定位、修改建议和建议条款。

预期路由：`contract_review`。

## 场景五：综合工作成果

要求把已确认事实、证据、企业信息、类案研究和合同风险整合为可视化案情梳理文档及律师工作报告。

预期路由：`legal_work_product`。

## 现场必须展示

- Router 决策和选中的 Subagent；
- 工具调用、耗时、来源与失败回退；
- 每项结论对应的原始材料或外部来源；
- DOCX/PDF、时间线和关系图等可交付文件；
- 敏感数据与 API 凭据不出现在日志和界面中。
