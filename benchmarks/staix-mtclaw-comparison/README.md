# Staix / MTClaw 法律智能体对照测试

本测试集包含三类智能体各 15 个任务，共 45 个任务。每个任务分别在 `Staix 直连` 与 `Staix + MTClaw` 下执行一次，共 90 次运行。

## 公平性控制

- 两组使用相同提示词、默认主智能体、模型配置、能力配置和工作区。
- 唯一自变量是 `mtclawRouter.enabled`。
- 每次运行使用全新会话，不继承上下文。
- 各任务交替执行顺序：奇数任务先直连，偶数任务先 MTClaw。
- 企业与法律研究任务使用公开信息；民事文书任务全部使用明确标注的虚构测试数据。
- 结构检查只判断必要字段是否出现，不替代律师对事实和法律正确性的人工复核。

## 分阶段执行

1. 小样本：每类智能体取第 1 个任务，两种模式各跑一次，共 6 次。
2. 小样本全部形成完整记录且 MTClaw 组存在 Router 路由证据后，再运行全量 90 次。
3. 运行结果按任务实时写入 JSONL，可在中断后续跑，不重复已完成的任务。

## 保存内容

- 原始提示词、完整回答、异常信息。
- 开始/结束时间、总耗时、首个进度事件耗时。
- 工具调用、模型交互、进度事件。
- MTClaw Router 的工具历史与子智能体角色证据。
- 每项结构检查结果，以及需人工复核的法律正确性标记。
- 汇总 CSV、JSON、Markdown 报告和文件 SHA-256 清单。

运行器不会修改用户的 Staix 配置文件。它读取现有配置到内存，在隔离的测试目录中切换模式并启动所需服务。
